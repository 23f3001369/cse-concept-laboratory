Chapter 2 · The Briefing

Back Again — The Browser Stack

Your history is a pile — every visit is pushed on top. You can only Back (pop) the top or peek at it.

  • Search Bar is not a stack — you can't jump to middle.
  • History search is disabled.
  • Every Visit → push on top
  • Back → pop the top only

Chapter 5 · The Method

How it really worked

You just lived a Stack. Here's the name for what you felt.

🥞

The Stack (LIFO)

Definition

LIFO — Last In, First Out. Like plates, you can only touch the top. Last thing you put in is first you get back.

Mechanism

push(x) — visit on top, pop() — Back removes top, peek() — glance at top. All O(1). No middle jump — must pop everything above.

Vocabulary

top — current page, underflow — Back on empty, overflow — push when full, LIFO.

If it were a Queue (FIFO)Back would give Google first — oldest, not last. Undo would erase H from HELLO → ELLO!
Because it’s a Stack (LIFO)Back gives last visited — exactly what you expect. Undo fixes last mistake.

🔑 Key Learnings

🥞
The Shape

Only the top is reachable. That constraint is the whole power — and the limit.

⚡
O(1) Top

Push, pop, peek never scan — they touch top only.

↩️
Where You'll See It

Browser Back, Ctrl+Z, call stack, plate pile — all want last action first.
