The idea behind it

Hashing, Explained

📦

Hashing is a technique that uses a mathematical function (called a hash function) to map a piece of data (like a name) directly to a specific storage location (like a bin number). Instead of searching through every possible location, you compute where the data should be and go straight there. The hash function takes a key and returns an index — that's the bin number. When two different keys produce the same index, it's called a collision, and the warehouse handles it by chaining — linking both items at the same bin.

The Hash Function (used in the game)
bin = (sum of ASCII values of letters) mod 20

For example, "ALI" → A(65) + L(76) + I(73) = 214 → 214 mod 20 = 14 → Bin 14. The mod operator ensures the result always fits within 0–19.

Hash Function
A mathematical formula that takes a key (like a name) and converts it into a number (an index or bin number).
Key
The input data you want to store or look up — like a sender's name or a username.
Bucket / Bin
The storage location where a key is placed, determined by the hash function's output.
Collision
When two different keys hash to the same bucket. This is handled by chaining (linking items) or other resolution strategies.
